# Vault'd Mobile Site

Mobile web prototype and launch scaffold for selling locked, permanent-unlock content.

## Quick Start

```powershell
copy .env.example .env
npm.cmd install
npm.cmd run check
npm.cmd run dev
```

Then open:

```text
http://localhost:8787/index.html
http://localhost:8787/fan.html
```
